## [v0.1.0] - 2026-05-23

### Highlights

- Unified signal ingestion abstraction for operational intelligence following the omnillm architectural pattern
- Built-in thick providers for PagerDuty and Jira with SDK-based implementations

### Added

- Core `Provider` interface with `Fetch`, `Subscribe`, `Capabilities`, and `Close` methods ([`194d497`](https://github.com/plexusone/omnisignal/commit/194d497))
- `FetchOptions` for filtering signals by time range, status, severity, and provider-specific filters ([`194d497`](https://github.com/plexusone/omnisignal/commit/194d497))
- `SubscribeOptions` for real-time streaming configuration ([`194d497`](https://github.com/plexusone/omnisignal/commit/194d497))
- `Capabilities` struct describing provider features (streaming, batch fetch, filtering, acknowledge) ([`194d497`](https://github.com/plexusone/omnisignal/commit/194d497))
- `Config` struct with `APIKey`, `APISecret`, `BaseURL`, `Timeout`, `RetryMax`, and `Options` fields ([`194d497`](https://github.com/plexusone/omnisignal/commit/194d497))
- Common errors: `ErrNotSupported`, `ErrInvalidConfig`, `ErrAuthentication`, `ErrRateLimited`, `ErrProviderNotFound` ([`194d497`](https://github.com/plexusone/omnisignal/commit/194d497))
- Provider registry with `Register`, `New`, `MustNew`, `List`, `IsRegistered`, `GetPriority` functions ([`8488b6d`](https://github.com/plexusone/omnisignal/commit/8488b6d))
- Priority-based registration allowing thick providers to override thin providers ([`8488b6d`](https://github.com/plexusone/omnisignal/commit/8488b6d))
- `Unregister` and `ClearRegistry` functions for testing ([`8488b6d`](https://github.com/plexusone/omnisignal/commit/8488b6d))
- PagerDuty provider using official `go-pagerduty` SDK ([`e9095d4`](https://github.com/plexusone/omnisignal/commit/e9095d4))
- PagerDuty incident fetching with pagination, time filtering, status/severity mapping ([`e9095d4`](https://github.com/plexusone/omnisignal/commit/e9095d4))
- PagerDuty incident normalization to signal-spec `Signal` type ([`e9095d4`](https://github.com/plexusone/omnisignal/commit/e9095d4))
- Jira provider using `go-jira` community SDK ([`ff331a2`](https://github.com/plexusone/omnisignal/commit/ff331a2))
- Jira issue fetching via JQL with project, time, status, priority filters ([`ff331a2`](https://github.com/plexusone/omnisignal/commit/ff331a2))
- Jira issue normalization to signal-spec `Signal` type with component entities and label tags ([`ff331a2`](https://github.com/plexusone/omnisignal/commit/ff331a2))
